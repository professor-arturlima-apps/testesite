1. Fundamentos da Convolução

A operação de convolução é o pilar central para a análise de sistemas lineares e invariantes no tempo (LTI). Definida formalmente como:

\[\displaystyle y(t) = (h * x)(t) = \int_{-\infty}^{\infty} h(\tau)x(t-\tau) \, d\tau\]

Em sistemas discretos, a operação é análoga, utilizando o somatório:

\[\displaystyle y[n] = \sum_{k=-\infty}^{\infty} h[k]x[n-k]\]

2. Análise Temporal

A convolução permite determinar a saída de um sistema dada uma entrada \(x(t)\) e uma resposta ao impulso \(h(t)\). Para sistemas causais, os limites de integração são ajustados:

\[\displaystyle y(t) = \int_{0}^{t} h(\tau)x(t-\tau) \, d\tau\]

Propriedades fundamentais:

  1. Comutatividade: \(\displaystyle x * h = h * x\)

  2. Distributividade: \(\displaystyle x * (h_1 + h_2) = x * h_1 + x * h_2\)

  3. Associatividade: \(\displaystyle x * (h_1 * h_2) = (x * h_1) * h_2\)

3. Transformada de Fourier

A extensão para o domínio da frequência é dada pela Transformada de Fourier, permitindo analisar espectros de sinais:

\[\displaystyle X(j\omega) = \int_{-\infty}^{\infty} x(t)e^{-j\omega t} \, dt\]

A relação de Parseval garante a conservação de energia no domínio do tempo e da frequência:

\[\displaystyle \int_{-\infty}^{\infty} |x(t)|^2 \, dt = \frac{1}{2\pi} \int_{-\infty}^{\infty} |X(j\omega)|^2 \, d\omega\]

4. Aplicações Práticas e Filtros

Sistemas LTI podem atuar como filtros seletivos de frequência.
